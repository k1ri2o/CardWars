# Card Wars in the browser

A rebuild of the Card Wars battle that runs in any modern browser, made for
playing **1v1 against a friend**: online by room code, on the same Wi-Fi
without internet, or passing one device back and forth. There is also a
practice mode against a simple computer opponent.

It uses the original game's rules, cards, heroes, decks and art from this
repository. The rules engine is a line-by-line port of `GameState.cs` and the
201 card and hero ability scripts in `Assets/Scripts/Assembly-CSharp/`.

## Ways to play

| Mode | What you need |
| --- | --- |
| **Online** (Host / Join with a code) | Both players open the game page. One taps *Host an online match* and reads out the 6-letter code or sends the invite link; the other taps *Join with a code*. |
| **Same Wi-Fi, no internet** | One computer runs the local server (below). Both players open the address it prints, then Host / Join as usual. |
| **Pass & play** | One phone, tablet or PC. The screen is covered between turns so hands stay hidden. |
| **Practice** | Play against the computer to learn the cards. |

Each player brings their own deck: one of the 26 preset decks from the
game's quests, or one made in the deck builder (pick a hero, four
landscapes and 10 to 60 cards, at most 4 copies of a card). Deck codes can be
shared with friends.

The host chooses the match rules: hero level (sets hero HP; level 15 is the
default), card level, the battle ring on or off, and an optional turn timer.

## Running it

### On GitHub Pages (online play)

The workflow in `.github/workflows/pages.yml` publishes this folder to
GitHub Pages on every push to `main` that touches `web/`. It needs Pages
switched on once: **Settings → Pages → Build and deployment → Source:
GitHub Actions**. The game is then at `https://<owner>.github.io/<repo>/`.
GitHub only offers Pages for private repositories on paid plans; for a
private repository on a free plan, use the local server below or upload this
folder to any static web host. The folder has no build step.

### On your own computer (LAN play, also works online)

Needs [Node.js](https://nodejs.org) 18 or newer.

- Windows: double-click `web/start.bat`
- macOS / Linux: run `web/start.sh`
- or: `cd web && npm start`

It prints addresses like `http://192.168.1.20:8080/`. Everyone on the same
network opens that address. If Windows asks whether Node.js may use the
network, allow it on private networks.

Opening `index.html` straight from disk does not work (browsers block
loading the card data from `file://`); use one of the options above, or any
static server such as `npx http-server web`.

## How online play works

- The host's browser runs the match. The guest sends its moves; the host
  checks them, applies them and sends each player only what that player may
  see (your opponent's hand never leaves the host).
- The two browsers talk directly over WebRTC using
  [PeerJS](https://peerjs.com). A signaling server only introduces them: the
  free PeerJS cloud server when the page comes from a normal web host, or the
  one built into `server/server.mjs` when the page comes from the local
  server, which is what makes LAN play work without internet.
- If the guest's connection drops or they reload the page, they rejoin the
  running match automatically. If the host closes their tab, the match ends.

## Code layout

```
web/
  index.html, style.css     the page
  js/engine/                rules engine (no DOM): game.js = GameState.cs,
                            cards.js, lane.js, scripts/*.js = ability scripts
  js/match.js               runs a match for the seats on this device
  js/session.js             practice / pass & play / online host / online guest
  js/net/peer.js            room codes and WebRTC connections
  js/bot.js                 practice opponent (also drives the soak test)
  js/ui/                    board, battle ring, menus, deck builder
  data/cards.json           generated by tools/build-data.mjs from Assets/
  assets/                   card art and atlases copied from Assets/
  server/                   optional LAN server (static files + signaling)
  test/                     node:test suites
```

Tests: `cd web && npm test` (engine, every ability script, host protocol,
and bot-vs-bot matches across all preset decks). After changing card data in
`Assets/`, run `npm run build-data`.

## Where it differs from the mobile game

The rules follow the C# code, including its quirks (each kept quirk has a
comment and a test). The changes are the ones two human players need:

- Both seats take the human path of every ability. Checks that only ran
  for the computer opponent (for example "only cast this if it leads to a
  legal move") are dropped.
- Values the original kept once for the single player (ring modifiers, the
  extra magic from Bad Rose) are kept per player.
- The original's defense ring had no effect. Its defense-area floops shrink
  the attacker's hit and crit zones instead.
- The ring's spin speed is an approximation of the original's, and the
  ring stops by itself after 8 seconds.
- The computer opponent is a simple greedy bot, not the original AI.
